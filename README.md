# OmniGuardy

OmniGuardy 모바일 앱(Expo / React Native).

## 다운로드

최신 테스트 APK는 [Releases](https://github.com/2026-GUARDIANS/omniguardy-frontend/releases)에서 받을 수 있습니다.

## 지원 기기

- **Android 7.0 이상** 스마트폰·태블릿 (제조사 무관: 갤럭시, 픽셀, LG, 샤오미 등)
  - 테스트 완료: Galaxy Tab S6 (SM-T860)
  - 태블릿에서도 세로 화면으로만 실행됩니다
- **iPhone·iPad: 지원하지 않음** (APK는 iOS에 설치할 수 없음. iOS 버전은 아직 준비 중)
- Google Play 서비스가 없는 기기(최근 화웨이 등): 앱은 실행되지만 푸시 알림은 받을 수 없음

## 설치 방법

1. [Releases](https://github.com/2026-GUARDIANS/omniguardy-frontend/releases)에서 최신 `.apk` 파일을 휴대폰으로 다운로드
2. 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용
3. 이전 버전이 설치돼 있으면 그 위에 업데이트됨
